Données Vivantes est un catalogue de visualisations de données interactives. Chacune explore un jeu de données ouvertes et le met en forme d'une façon qui lui est propre.

## La démarche

Ici, pas de modèle de graphique appliqué d'un jeu de données à l'autre. Chaque visualisation est une pièce à part : sa forme est choisie pour ce que les données ont à montrer, qu'il s'agisse d'une carte animée, d'un calendrier circulaire, de petits multiples ou d'une nuée de points autour d'un globe. L'idée est de donner envie d'explorer, puis de laisser chacun manipuler la représentation pour se faire sa propre idée.

## Les données

Toutes les données viennent de sources publiques : organismes publics, instituts scientifiques, associations de conservation, projets collaboratifs. Chaque page cite ses sources avec leur producteur, leur licence et la date à laquelle elles ont été récupérées : les données ouvertes évoluent, et cette date indique la version réellement utilisée.

Les données sont préparées et figées au moment de la construction du site, sauf exception signalée sur la page concernée. Quand un jeu de données a des limites connues (couverture partielle, biais de documentation, observations plutôt que recensement), la page le dit.

Quand les licences des sources le permettent, les fichiers préparés pour une visualisation peuvent être téléchargés depuis sa page. Leur réutilisation reste soumise aux licences de ces sources.

## Partager une vue

L'adresse d'une visualisation suit ce que vous en faites : filtres, année mise en pause, zone agrandie sur une carte. Copier cette adresse suffit pour partager exactement la vue affichée.

## Fabrication

Le site est statique, généré avec [Astro](https://astro.build) et hébergé sur GitHub Pages. Les visualisations sont codées une par une, principalement avec [D3](https://d3js.org) et Canvas. Le code source est public sur [GitHub](https://github.com/cheubes/dataviz.heubes.io).

Aucune mesure d'audience, aucun cookie : seule votre préférence de langue est mémorisée, dans votre navigateur.
